Remote debugging and secret sharing over the terminal.
Nothing runs without a yes. Nothing leaks in transit.

Remote Debug
Request shell commands on a customer's machine. Every command needs explicit approval.
$ curl -sL shellshock.sh/get | bash
Share Secrets
End-to-end encrypted. The server never sees the decryption key. Burns after first retrieval.
$ npx shellshock.sh
then press Ctrl+S to share a secret
